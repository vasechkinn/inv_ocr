# OCR Invoice Parser

Проект представляет собой веб-сервис для парсинга счетов (инвойсов) с использованием методов оптического распознавания символов (OCR). Приложение построено на **FastAPI**, использует **PaddleOCR** для распознавания изображений и **MySQL** для хранения данных.

## 📋 Возможности

*   **Распознавание документов**: Извлечение данных из счетов с помощью PaddleOCR.
*   **Аутентификация**: Защита маршрутов с помощью JWT (JSON Web Tokens).
*   **База данных**: Хранение пользователей и распознанных данных в MySQL.
*   **Web-интерфейс**: Встроенный интерфейс для загрузки файлов и просмотра результатов.
*   **FastAPI**: Современный, быстрый API с автоматической документацией (Swagger).

## 🛠 Установка и настройка

### 1. Клонирование репозитория

```bash
git clone https://github.com/vasechkinn/inv_ocr.git
cd inv_ocr
```

### 2. Создание окружения

Рекомендуется использовать `venv` или `conda`.

```bash
# Создание виртуального окружения
python -m venv venv

# Активация (Windows)
venv\Scripts\activate

# Активация (Linux/Mac)
source venv/bin/activate
```

### 3. Установка зависимостей

Для работы с CPU:

```bash
pip install -r requirements-cpu.txt
```

Если требуется GPU (NVIDIA):

```bash
pip install -r requirements-gpu.txt
```

### 4. Настройка базы данных

1.  Создайте базу данных в MySQL.
2.  Создайте пользователя для базы данных и предоставьте ему права.

### 5. На переменные окружения

Скопируйте файл шаблона в `.env`:

```bash
cp .env.example .env
```

Откройте `.env` и укажите ваши данные:

```env
DB_HOST=127.0.0.1
DB_USER=ваш_пользователь
DB_PASSWORD=ваш_пароль
DB_NAME=ваше_имя_базы

JWT_SECRET_KEY=ваш_секретный_ключ
```

## 🚀 Запуск

Для запуска сервера разработки выполните:

```bash
uvicorn main:app --reload
```

Сервер запустится по адресу: `http://127.0.0.1:8000`

*   **API документация (Swagger):** `http://127.0.0.1:8000/docs`
*   **Интерфейс ReDoc:** `http://127.0.0.1:8000/redoc`

## 📁 Структура проекта

*   `main.py` — Точка входа приложения, инициализация FastAPI.
*   `database.py` — Настройка подключения к базе данных (SQLAlchemy).
*   `models.py` — Модели базы данных (SQLAlchemy).
*   `schemas.py` — Pydantic-модели для валидации данных.
*   `security.py` — Логика аутентификации и JWT.
*   `ocr_services/` — Сервисы для работы с OCR (PaddleOCR).
*   `web_app/` — Фронтенд (HTML/CSS/JS) и маршруты (Routers).

## ⚠️ Примечания

*   Для работы OCR убедитесь, что у вас установлены необходимые библиотеки и модели PaddleOCR.
*   Для GPU-версии требуется драйвер NVIDIA CUDA.
